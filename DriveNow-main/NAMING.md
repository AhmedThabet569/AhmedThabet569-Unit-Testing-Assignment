# Naming 
1- all interface must start with an uppercase letter and end with the word "Interface". For example, `UserInterface`, `ProductInterface`, etc.
2- all service classes must start with an uppercase letter and end with the word "Service". For example, `UserService`, `ProductService`, etc.
3- all repository classes must start with an uppercase letter and end with the word "Repository". For example, `UserRepository`, `ProductRepository`, etc.
4-all executable classes must start with an uppercase letter and end with the word "Executable". For example, `UserExecutable`, `ProductExecutable`, etc.
